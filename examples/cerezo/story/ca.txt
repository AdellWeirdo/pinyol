// Cerezo: les converses, en català. Cada == és un nus; el nom abans dels dos punts és qui parla.
// Les coses que passen (donar, pagar, marcar) són funcions de core/quest.lua; els indicadors són els mateixos que en castellà.

// ------------------------------------------------------------------ el principi
== intro_1
Fa molt de temps, a l'Illa Cirerer, va néixer un cirerer enorme.
Cada primavera, tothom sortia a veure'l florir.
-> END

== intro_2
Però aquest any la primavera va arribar...
i el cirerer no es va despertar.
-> END

== intro_3
Brot, el net jardiner, encara dorm.
Aviat sentirà la seva àvia.
-> END

== intro_yaya_llama
Iaia: Brot! Brot, aixeca't, que el sol ja és sobre l'hort!
-> END

== intro_cama
Brot: Cinc minuts més...
Iaia: Ni un! Baixa, que tinc una cosa per a tu.
-> END

== intro_pala
Iaia: Aquesta pala era del teu avi. Talla la mala herba i cava on la terra sigui fluixa.
Iaia: I no t'oblidis de passar per la plaça: la Dona Figuera et vol parlar.
-> END

// ------------------------------------------------------------------ la Iaia
== yaya
[if flag("tree_bloomed")] Iaia: El teu avi hauria plorat d'alegria. Jo ploro per tots dos.
[if flag("tree_bloomed")] -> END
[if flag("topo_dead")] Iaia: És veritat el que diuen? Un talp amb una corona? Ai, el meu nen!
[if flag("topo_dead")] Iaia: Corre a la plaça, que el cirerer t'espera.
[if flag("topo_dead")] -> END
[if flag("seal_open")] Iaia: La Arrel... El teu avi mai no hi va baixar. Vés amb compte i porta el fanal.
[if flag("seal_open")] -> END

[if not flag("higuera_met")] -> END

Iaia: Cada cosa a son temps, i el cirerer a la primavera.
-> END

-> END

// ------------------------------------------------------------------ la Dona Figuera
== higuera

[if flag("tree_bloomed")] -> END

[if flag("topo_dead")] -> END

[if flag("seal_open")] -> END

[if flag("higuera_met")] Dona Figuera: Pregunta a l'Espantaocells, a la Gla i a la Sardina: l'illa guarda els seus secrets.
[if flag("higuera_met")] -> END
[do setflag("higuera_met")]

Dona Figuera: Sota el mont hi ha una cova, l'Arrel. La porta només s'obre amb tres pinyols d'or.
Dona Figuera: Pregunta a l'Espantaocells, a la Gla i a la Sardina. Jo tindré cura de la plaça.
-> END

// ------------------------------------------------------------------ l'Oncle Noguer i la botiga
== nogal
[if flag("tree_bloomed")] Oncle Noguer: Avui tot a meitat de preu! Bé, a dos terços. Bé, de res.
[if flag("tree_bloomed")] -> END
Oncle Noguer: Benvingut a la botiga del Noguer, tresor! El millor de l'hort.
-> tienda

== tienda
+ [if not flag("pieza_comprada")] Tros de cor: 60 -> comprar_pieza
+ 10 pinyols: 8 -> comprar_pinyoles
+ Suc de cirera: 15 -> comprar_zumo
+ Res, gràcies -> nogal_adios

== comprar_pieza
[do ok = pay(60)]
[if ok] Oncle Noguer: Un tros de cor! Cuida'l, que ja no se'n fan.
[if ok] [do setflag("pieza_comprada")]
[if ok] [do give("pieza_corazon")]
[if not ok] Oncle Noguer: Et falten cireres, tresor. Talla molta herba.
-> nogal_fin

== comprar_pinyoles
[do ok = pay(8)]
[if ok] Oncle Noguer: Deu pinyols! Amb aquests no falles.
[if ok] [do give_pinyoles(10)]
[if not ok] Oncle Noguer: Amb el que portes no n'hi ha prou, tresor.
-> tienda

== comprar_zumo
[do ok = pay(15)]
[if ok] Oncle Noguer: Glu, glu, glu! Com nou!
[if ok] [do heal_all()]
[if not ok] Oncle Noguer: Quinze cireres, i això és medicina.
-> tienda

== nogal_adios
Oncle Noguer: Torna quan vulguis, i porta cireres!
-> END

== nogal_fin
Oncle Noguer: Torna quan vulguis!
-> END
